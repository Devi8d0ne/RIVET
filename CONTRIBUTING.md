# Contributing to RIVET

RIVET is early software aimed at real local productions. Small, testable changes are easiest to review.

1. Open an issue describing the production problem or device gap.
2. Keep stream keys, signed upload links, recordings, and device identifiers out of commits and logs.
3. Build the frontend and run the relevant Python and JavaScript tests.
4. For Android changes, report the phone model, Android version, Termux source/version, browser version, quality profile, test duration, and whether hardware encoding was enabled.
5. Explain what changed, why, and how you verified it in the pull request.

Device support claims require evidence from the actual device. A short synthetic encode is useful, but it does not prove full-event thermal or audiovisual reliability.
